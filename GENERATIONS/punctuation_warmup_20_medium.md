# Punctuation Warmup — 20 Medium Questions

Choose the answer that completes each text so that it conforms to the conventions of Standard English. Replace `_____` with the entire choice. An em dash closes directly against the preceding word; surrounding display spaces are not being tested.

This set adds embedded clauses, longer appositives, and transitions near sentence boundaries. Difficulty is an instructional estimate, not an empirically calibrated rating.
